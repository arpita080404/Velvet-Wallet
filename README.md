# Velvet Wallet 💜

Velvet Wallet is a modern Android-based expense tracking and house budget planner application developed using **Kotlin**, **MVVM Architecture**, and **Room Database**.  

The app helps users manage personal and household finances through expense tracking, budget monitoring, analytics, and smart financial insights in a clean and user-friendly interface.

---

# ✨ Features

## 💰 Expense & Income Management

- Add income and expense transactions
- Edit and delete transactions
- Category-wise transaction management
- Custom categories support
- Notes support for transactions
- Future date restriction for better data consistency
- Currency symbol customization

---

## 📊 Analytics Dashboard

- Monthly expense tracking
- Income vs expense overview
- Net balance calculation
- Budget usage visualization
- Category-wise analytics and insights

---

## 🔒 Security Features

- PIN lock support
- Biometric authentication support

---

## ⚙️ Settings & Utilities

- Monthly budget cap management
- CSV export functionality
- Clear all transaction data option
- User customization settings

---

# 🧠 Smart Features

- Spending insight generation
- Prediction engine for financial analysis
- Structured data handling using Room Database

---

# 🏗️ Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM
- **Database:** Room Database
- **UI Components:** Material Design Components
- **Charts & Analytics:** MPAndroidChart
- **Asynchronous Tasks:** Kotlin Coroutines
- **View Binding:** Enabled

# 🚀 Installation

## Clone the repository

```bash
git clone https://github.com/arpita080404/Velvet Wallet.git
```

---

## Open in Android Studio

* Open Android Studio
* Select **Open Project**
* Choose the cloned project folder

---

## Run the Application

* Connect an Android device or emulator
* Click ▶ Run
